Network Topology Mapper ヘルプ

自分が管理するネットワークの構成確認と、不調の切り分けを行うツールです。

最初に行うこと

メニューで 1 の「フル実行」を選んでください。診断、速度測定、60秒の通信品質モニタ、LAN の機器調査、構成図、AI修正依頼をまとめて作成します。

開始前に対象 LAN と通信量を表示します。内容を確認して開始すると、完了後に HTML レポートが自動で開きます。

メニューの説明

1 フル実行診断、速度測定、通信品質モニタ、LAN 調査、機器特定、HTML レポート生成を一括実行します。完了後にレポートを自動で開きます。
2 その他の機能基本診断、外部通信なしの LAN レポート、モニタ、修復、定期実行、公開用レポート、軽量モードをまとめています。
O 前回の結果最後に生成した通常レポート output\diagram.html を開きます。
H ヘルプこのページを開きます。
Q 終了アプリを終了します。

2 の中では、必要な機能だけを個別に実行できます。外部通信なしでレポートを作りたい場合は「LANレポート」を選んでください。

フル実行の確認画面

実行前に対象 NIC、CIDR、最大ホスト数、外部通信、速度測定の上限、通信品質の監視時間を表示します。内容が自分または組織から許可された範囲と一致するときだけ y を入力してください。Enter だけなら開始しません。

職場、学校、宿泊施設、公衆 Wi-Fi、他人のネットワークを無断で調査しないでください。

VPN、仮想 NIC、Bluetooth、コンテナ、広すぎるネットワークは自動的に対象外です。「パブリック」プロファイルは警告付きで表示します。

結果の見方

pass測定した範囲では問題なし。
warn改善の余地または注意点があります。
fail通信を妨げる問題が疑われます。
skip前提がそろわず測定していません。

最初に読む場所

「診断」タブの推定原因と根拠を確認します。判定は測定時点の推定なので、ケーブル交換や設定変更の後は再測定してください。

通信品質と速度

「モニタ」タブでは、遅延、損失、ジッター、スパイク、瞬断を時系列グラフで確認できます。同じ画面に下り・上り速度の現在値、履歴グラフ、実測値の表も表示します。速度の診断結果は原因判定の根拠として「診断」にも残ります。

AI修正依頼

改善点がある場合、すべての問題、根拠、取得できた実際の数値を一つのプロンプトにまとめます。「AI修正依頼」タブのボタンでコピーでき、同じ内容を output\ai-repair-prompt.txt にも保存します。

プロンプトは、複数の問題を分割せずまとめて直し、再測定するよう AI に依頼します。管理者権限、通信断、ルーター変更、課金、不可逆操作が必要な場合は、先に利用者へ確認する指示も含みます。

通信量とプライバシー

  • フル実行は、確認画面に表示した外部サービスと速度測定を使用します。
  • その他の機能にある基本診断と「LANレポート」は、外部サービスへ通信しません。
  • 外部サービスへ接続すると、提供者には接続元の公開 IP、時刻、User-Agent など通常の通信情報が見えます。
  • 速度測定では生成した測定用バイト列を Cloudflare へ送信します。診断結果や端末一覧は送信しません。
  • 通常の結果はこの PC の output に保存されます。IP、MAC、SSID、端末名などを含むため秘密情報として扱ってください。

プライバシーの詳細 / 外部通信先の一覧

公開用レポート

P は IP、MAC、PC 名、ユーザー名、SSID、端末名などを仮名へ置換し、履歴、プロセス、接続先、外部回線情報などを除外した別ファイルを作ります。

仮名化は匿名化の保証ではありません。端末数、珍しい構成、時刻、測定値などから環境を推測できる場合があります。HTML、CSV、AIプロンプトを公開する前に必ず目視確認してください。

困ったとき

詳細調査を開始できない

信頼できる自宅 LAN が Windows で「プライベート」に設定されているか確認してください。「パブリック」のまま詳細調査を許可する回避策は用意していません。

構成図だけ表示されない

初回の Mermaid がまだない可能性があります。許可できる環境なら、詳細調査で外部情報の取得に y と答えてください。固定版を取得し、SHA-256 が一致した場合だけ使います。診断表と AI 修正依頼は Mermaid がなくても読めます。

端末が見つからない

スリープ、Wi-Fi のクライアント分離、ファイアウォール、ランダム MAC などにより応答しない端末があります。表示は全端末の存在を保証しません。

修復を元に戻したい

F → 3 を選びます。AI の提案を別に実行した変更は、このロールバックの対象外です。

CLI を含む詳しい手順は docs/README.md にあります。
